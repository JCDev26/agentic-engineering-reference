# Checkpoint memory and specialist steering

A release report includes suite and timing sections. Security finds evidence that two timing samples might have ended at login. It addresses Performance directly. The conductor sees the message and holds the timing section while Reporting finishes the suite section.

Performance checks the final routes. Sample 18 ended at login, sample 19 reached the expected page, and a replacement restores the workload. When Reporting reconnects, it loads the latest checkpoint for its own job and branch, reads its missed mail, and replaces the stale draft. The decision to act still requires current evidence and authority.

| Ask the target's agent | Observation that challenges the answer |
| --- | --- |
| Which facts survive resume? | Revoke a grant while the worker is away. Its passing suite may still be current while its grant is contradicted. |
| Can a specialist steer a peer without stopping the team? | Deliver a finding during an in-flight write. Observe the affected commit and an unrelated write. |
| Who can resolve a finding? | Send an acknowledgment and inspect whether the finding still awaits independent evidence. |
| What if a worker returns with an old draft? | Replace the connection or change the source. Inspect whether the old draft can commit. |
