## Official compatibility and security basis

- [Node 22.23.4](https://nodejs.org/en/blog/release/v22.23.4) is a security release.
  [Node 24.22.2](https://nodejs.org/en/blog/release/v24.22.2) is a supported LTS
  patch; [Node's release schedule](https://nodejs.org/en/about/previous-releases)
  lists both lines as supported. Preserve the existing 22/24 support lines, update
  their exact CI pins, and use 24.22.2 in `.node-version`. Engines now express these
  two supported major lines rather than admitting unsupported odd majors.

  npm 11.19.1 with Node 24.22.2. Downloaded portable Windows x64 archives were checked
  against Node's HTTPS `SHASUMS256.txt`; no global installation was changed. This was
  checksum verification, not an independent signature-verification claim.

  mock hardening. [Manual mock injection](https://github.com/advisories/GHSA-qxg6-89mg-rqv8)
  requires mocker 4.1.12; [redirect mock traversal](https://github.com/advisories/GHSA-82fw-gwwq-j7x9)
  was fixed at 4.1.11. Registry engines include both supported Node lines.
- [Vite 6.4.5](https://github.com/vitejs/vite/releases/tag/v6.4.5) keeps the existing
  transitive major. The [launch-editor advisory](https://github.com/advisories/GHSA-587h-7wmj-h5pm)

  range accepts both supported pins; Vitest 4.1.12 permits Vite 6.

  indexed-map denial of service. Overrides select Vite 6.4.5 and source-map-js 1.2.2
  while retaining supported parent ranges. Reconsider the overrides when parent
  dependencies no longer need them; do not force a major Vitest/Vite migration.

  major instead of allowing Node 26-only APIs to typecheck. TypeScript remains 7.0.2.
  This corrects the compatibility contract; no existing Node 26-only runtime use
