# Calibrate a reviewer

Give two reviewers the same claim and withhold the observations until both commit to their first answers. Ask one for an ordinary assessment and the other for a prediction, a counterexample and a positive control. Then give both the same packet, which should contain a known defect, a sound case and a case with unavailable evidence.

In the reservation pilot both reviewers judged all three cases correctly. The ordinary reviewer cited the trial ledger in all three answers. The two-pass reviewer also cited the control in all three. This small comparison leaves broader defect-detection performance open.

The [Playwright Wrapper](https://github.com/JCDev26/playwright-agent-wrapper-starter) contains the recorded responses and optional calibration exercise. A human can perform the same comparison using this protocol and a held-out target case.
