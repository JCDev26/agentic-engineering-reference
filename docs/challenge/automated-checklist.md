# Two-pass review worksheet

Record the target, commit and operation. Save the respondent's answers to the [twenty questions](claim-checklist.md) before giving the challenger the [pressure-test prompt](pressure-test-prompt.md).

| Claim ID and original answer | Prediction and proposed control | Contrary observation | Observed effect and evidence | Verdict and limits |
| --- | --- | --- | --- | --- |
| C13 · Retrying a lost reservation reply always leaves one booking. | On a fresh desk, the same request ID should return the original booking. | A new ID for the same intent leaves two bookings. | Record the actual independent ledger count and the target revision. | Judge the stated scope against that observation. |

Use **supported within tested scope**, **contradicted** or **inconclusive**. Keep evidence gaps visible. A reviewer can complete this record in chat or Markdown. The [Playwright Wrapper](https://github.com/JCDev26/playwright-agent-wrapper-starter) hosts the optional worksheet generator.
